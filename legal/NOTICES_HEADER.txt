1. AI COMPONENTS (downloaded on first use, never bundled)
--------------------------------------------------------------------------
These files are downloaded from the URLs below (pinned to an exact version/commit,
SHA-256 verified) only when the user starts an AI feature and confirms the download.
They are stored unmodified in the app data folder (…\com.vho.app\ai\<component>\),
together with their license files.

1.1 ONNX Runtime Web 1.30.0 — inference engine (WebGPU / WebAssembly)
    Copyright (c) Microsoft Corporation. MIT License (full text in section 4.1).
    Source: https://github.com/microsoft/onnxruntime (tag v1.30.0)
    Download: https://cdn.jsdelivr.net/npm/onnxruntime-web@1.30.0/dist/
    The third-party notices of ONNX Runtime (ThirdPartyNotices.txt) are downloaded
    and stored next to the runtime: …\ai\ort-web\ThirdPartyNotices.txt

1.2 "4xRealWebPhoto_v4_dat2" photo restoration model
    Creator: Philip Hofmann (Phhofm)
    Source: https://huggingface.co/Phips/4xRealWebPhoto_v4_dat2
            (commit 95e9cd50553951c27d86bafbdc1bc27ca8e750d2, file 4xRealWebPhoto_v4_fp32_opset17.onnx)
    License: Creative Commons Attribution 4.0 International (CC BY 4.0)
             https://creativecommons.org/licenses/by/4.0/
    Changes: the file on disk is kept exactly as published. At load time, in memory only,
    VHO renames the two symbolic output dimension names ("height"/"width" -> "oeight"/"oidth")
    because the export reuses the input's names for the 4x larger output, which the WebGPU
    backend rejects. Weights and computation are unchanged (output verified bit-identical).
    The work is provided "as is"; see the CC BY 4.0 disclaimer of warranties.
    Use of the model does not imply endorsement of VHO by the creator.
    Architecture: DAT (Dual Aggregation Transformer), Zheng Chen et al.,
    https://github.com/zhengchen1999/DAT — Apache License 2.0.

1.3 YuNet face detector (face_detection_yunet_2023mar.onnx)
    Copyright (c) 2020 Shiqi Yu. MIT License (full text in section 4.1).
    Source: https://huggingface.co/opencv/face_detection_yunet
            (commit 3cc26e7f1014a5ee5d74a42acee58bafc9d0a310), https://github.com/ShiqiYu/libfacedetection.train
    Changes: none.

1.4 GFPGAN v1.4 face restoration model (ONNX export with float16-stored weights)
    Copyright (C) 2021 THL A29 Limited, a Tencent company. All rights reserved.
    Licensed under the Apache License, Version 2.0 (full text in section 5, "Apache License 2.0").
    Source: https://github.com/TencentARC/GFPGAN
    ONNX export used: https://huggingface.co/opiumuseless/gfpgan-v1.4-w16
            (commit 996691710925f8f44f0896490b8ff3d7a559398a, Apache-2.0) — the export stores
            weights as float16 and casts them to float32 at load.
    GFPGAN's LICENSE lists third-party components (StyleGAN2 CUDA ops under the NVIDIA
    Source Code License, DFDNet under CC BY-NC-SA 4.0). VHO uses neither: v1.4 is the
    "clean" architecture that needs no custom CUDA ops, and DFDNet is not used.

3. USED BUT NOT DISTRIBUTED BY VHO
--------------------------------------------------------------------------
- Microsoft Edge WebView2 Runtime and Windows Media Foundation: operating system
  components, already installed on Windows; VHO only calls them.
- Photo codecs of the operating system, used only when installed: Windows Imaging
  Component with the Microsoft Store "HEIF Image Extensions", "HEVC Video Extensions",
  "AV1 Video Extension" and "Raw Image Extension"; macOS ImageIO (sips); on Linux the
  libheif command-line tools (LGPL, run as a separate process, not linked or shipped).
- "Outfit" typeface (SIL Open Font License 1.1), loaded from Google Fonts.
